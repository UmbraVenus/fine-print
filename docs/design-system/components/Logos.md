# Logos

Text is outlined, so these look identical everywhere, with or without Inter installed. Fixed colors: `ink` text, `mint` lens, and an `ink` P.

- `fineprint-wordmark.svg` — The B2 wordmark: "Fine Print" with the P under the lens. Headers, README, slides; on `surface` or `surface-subtle`.
- `fineprint-wordmark-dark.svg` — The same on dark backgrounds: light text and lens outline, the P stays `ink` on the mint.
- `fineprint-mark.svg` — The lens and P alone: favicon, app icon, tight spaces.
